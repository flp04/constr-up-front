# Constr-Up-API

Aplicação desenvolvida em Vue.js para teste técnico da empresa Constr Up com a funcionalidade de gerenciar produtos

## Tecnologias

- Vue.js
- Vite
- Axios

## Como executar

Após clonar o repositório, instale as dependências:
  - npm install

Rode o projeto:
  - npm run dev

## Funcionalidades
- Cadastrar produto
- Visualizar produto
- Editar produto
- Excluir produto


## Decisões de implementação

- Service: optei por manter as operações do CRUD na View, em vez de encapsular em services, devido à simplicidade da aplicação e para evitar uma complexidade desnecessária.
